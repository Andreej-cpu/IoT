# Missione 11: Blink

## Dettagli e Requisiti


### Requisiti
Implementare un led lampeggiante.

### Obiettivo
Tempi: 182 millisecondi ON poi 182 ms OFF. Interrompere il lampeggiamento e spegnere dopo 20 ripetizioni di ON OFF.

NB: dato che ogni lampeggiamento dura nel complesso 182+182 ms, si dovrebbe osservare uno spegnimento dopo circa 7 secondi (364ms x 20).
