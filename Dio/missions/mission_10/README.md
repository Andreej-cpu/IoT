# Missione 10: Interfacc

## Dettagli e Requisiti


### Requisiti
Mantenere il circuito precedente con i LED, il sensore PIR e il sensore ultrasonico.

### Obiettivo
Utilizzare la piattaforma blynk.io per creare una dashboard Web per interagire a distanza col sistema di allarme.
L'interfaccia Blynk dovrà avere:
1. Uno switch per abilitare/disabilitare gli allarmi LED generati dai sensori.
2. Un elemento visivo che mostri l'attuale stato del LED rosso (acceso/spento).
3. Un elemento che visualizzi il contatore del numero di volte in cui si sono verificati "eventi critici" (entrambi i sensori attivati).
