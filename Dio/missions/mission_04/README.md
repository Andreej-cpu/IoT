# Missione 04: Personal Celsius

## Dettagli e Requisiti


### Requisiti
Mantenere il circuito precedente.

### Obiettivo
Connettere un sensore di temperatura analogico (potrebbe essere un TMP36 oppure un LM35, connettere correttamente).
Leggere l'uscita ogni secondo e convertire il valore. Controllare i grafici di riferimento per ipotizzare quale sia la curva di conversione corretta per ricavare la temperatura.
Visualizzare la temperatura calcolata sul monitor seriale.
