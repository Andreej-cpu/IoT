# wokwi-nokia-5110-screen Reference

The Nokia 5110 is a basic graphic LCD screen for lots of applications.

The monochrome display has an 84 x 48 pixel resolution.

![Nokia 5110 screen](../assets/images/wokwi-nokia-5110-screen-324359283dfff023ff57e800e0a3d153.svg)

## Pin names

| Name | Description |
| --- | --- |
| RST | Reset pin |
| CE | Chip enable |
| DC | Data/Command select |
| DIN | Serial data input |
| CLK | Serial clock input |
| VCC | Supply voltage |
| BL | Backlight control |
| GND | Ground |
